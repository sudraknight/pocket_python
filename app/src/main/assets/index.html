 POCKET PYTHON 1.0

Python, in your pocket.

A local Python 3.13 interpreter with a focused editor. No account or internet connection is needed to run code.

Included libraries

Python’s Android-compatible standard library plus NumPy, Requests, SymPy and Pillow (PIL).

Try math, random, datetime, json, re, pathlib, statistics, sqlite3, asyncio, urllib and more. Import your own .py modules into the same workspace.

Good to know

Each run starts fresh. Use input() to type in the terminal. Stop interrupts a running program. Files save automatically; Export makes a copy in a folder you choose.

The terminal shows program output and accepts Python input. It is not an Android shell or a pip installer. Extra packages require an app rebuild. Desktop GUI modules (Tkinter, Turtle), desktop executables and most multiprocessing features are unavailable. Internet requests need a connection.
